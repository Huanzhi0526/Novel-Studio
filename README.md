# 个人小说写作工作台

Windows本地小说写作软件，包含原创写作、参考检索、主动AI扩写和按书创作助手。当前正式版 **0.2.10**（2026-11-15）；近期参考库记录为86部，属于此前入库核验时点，本轮文档维护未重新盘库。

开发接手从[协作规则](AGENTS.md)、[当前交接](HANDOFF.md)开始；[维护地图](docs/maintenance.md)定位代码，[发布清单](docs/release-checklist.md)说明隔离验收和升级。

## 安装与资料

- 当前安装包：release/NovelStudio-0.2.10-x64-Setup.exe；源码包与SHA256清单使用同版本文件名。安装包由本机生成、未签名，升级前正常退出以完成保存。
- 正式程序：`%LOCALAPPDATA%\Programs\Novel Studio`；正式资料：`%LOCALAPPDATA%\Novel Studio`。本机分别为`C:\Users\78828\AppData\Local\Programs\Novel Studio`与`C:\Users\78828\AppData\Local\Novel Studio`。
- 原创使用library.sqlite，正式参考使用独立reference-v2.sqlite；配置、加密凭证以及assistant-books聊天/记忆也在资料目录，不能只备份一个数据库就当全资料备份。
- 本机离线语义模型由正式embedding.json引用项目.local/model，Vulkan运行库位于正式资料runtime/llama-cpp-vulkan，保留CPU回退。已有向量无需因程序或文档更新重算。迁机时另带模型与原文资源，按实际配置核对路径，见[本地模型说明](model/README.md)。

## 原创写作

打开或新建作品；新作品自动创建第一卷和第一章，重启时可回到最近作品。左侧管理卷章，右侧工具栏可查看/新建大纲、角色、设定，或打开对照、参考与助手。顶部“书架”先保存再返回；正文停输后自动保存，也可Ctrl+S。

- 写作设置可调纸张、字体、字号、行距、缩进，以及限制宽度/跟随窗口；界面明暗和主题色在“资料与设置→外观与阅读”独立设置。
- 拖动正文和右侧栏之间的分界线可调宽，自动记住。方向键微调、Shift加速、双击恢复默认；缩窗临时限制宽度，窄窗使用覆盖侧栏。
- 选中文字可添加标记；“历史”可预览和恢复正文版本。删除有效标记后可短时撤销，正文已变化时会拒绝用旧位置恢复。
- 工具栏“更多”提供一键整理、重命名和TXT导出等；Ctrl+K整理正文，Ctrl+Z撤销。专注模式用Esc退出。显示偏好不改原稿文字。

## 参考检索与阅读

参考库顶栏可切换检索和书架，按作品及侧重缩小范围。现行KB v2包含档案切面、剧情场次账本和原文描写索引；知识卡是这些条目的阅读形式。

- **本地混合**：本机关键词和语义检索，不调用外部生成模型。
- **AI快速**：展开问题、混合召回并精选候选，问题与候选摘录交给所选服务。
- **AI深度翻书**：多轮查看参考条目和所需原文再核证；发送范围比快速模式更大。

结果先显示三行短预览，宽窗并排、窄侧栏单列。点标题或“展开全文”查看完整卡；展开“原文”后点击证据进入对应版本。分页仍由“加载更多”领取后续结果，当前返回条数不等于全书/全库同类情节总量。

从书架卷册或证据进入独立阅读页，可切目录、字号及返回原位置。正式v2卡在工作台只读，不提供旧版九类卡编辑或标准结果ZIP导入入口。旧卡规则、旧256卷快照和拆书交接包是历史兼容材料，不能用来覆盖现库。新增参考或建库实验应另定范围，在隔离目录构建并核验后才处理正式资料。

## 模型来源与AI扩写

检索和扩写分别保存模型来源与API配置。在对应设置中选择：

- 反重力账号：刷新本机agy.exe可用模型，选择家族和思考强度，复用CLI登录与账号额度。
- 兼容API：填写完整Chat Completions地址、模型及API Key，远程使用HTTPS，本机服务可用HTTP。
- 自动（检索）：优先已配置兼容API，否则尝试反重力；失败明确说明并可降级本地。扩写按其独立来源配置，不跟随检索选模。

刷新模型只读取目录；连接测试发送固定句，不能当正式内容质量或所有模型均可用的证明。切换来源不删除原API配置；凭证通过系统加密保存，旧配置仍可切回。

扩写在原创章节选中括号提示后主动点击“AI扩写”；可选本书资料，发送选区所需有限上下文。先生成原位预览，采纳后才写入，取消/失败保留原稿。扩写为独立单次调用，无持续聊天记忆；参考库不自动参与扩写。反重力或API实际接收这次必要的文字，不能因选择账号来源就把它当纯本地推理。

## 创作助手

左侧“创作助手”或写作右侧“助手”都可使用，两处共享本书会话与草稿。选书后从右上角菜单“模型与记忆”选择反重力模型、补充灵感/主旨/偏好。助手按需读本书资料，委托检索AI找依据，再汇总建议；不会自动发送当前章节全文或直接改写原稿。

Enter发送，Shift+Enter换行（Ctrl/⌘+Enter兼容）。忙碌时可继续草拟、停止本轮；切页/收起侧栏保留草稿。建议分段显示，短表正常渲染，长表转成逐幕分节；格式转换不改历史聊天原文。

长期记忆在每本书工作区AGENTS.md，作者可编辑；只有确认决定应记录为确定。使用说明和发送范围在记忆面板，快捷键也可悬停输入框查看。[助手说明](docs/创作助手.md) · [阅读与预览规则](docs/阅读体验优化.md)

## 备份与恢复

应用“导出备份”生成数据库一致快照，现行支持原创和v2参考双库。它不包含模型、API配置/密钥及assistant-books聊天/记忆；这些需另行保存。程序升级前的全资料目录备份与应用数据库ZIP属于不同层次。

恢复优先使用应用入口验证并恢复对应备份；现行双库恢复带失败回退。旧版单库ZIP仅代表旧共库，不能当当前双库全量备份。不要只复制library.sqlite覆盖当前资料，或拿旧卡/旧卷快照无条件回滚新稿。人工恢复前正常退出，保留当前完整资料，并按当次备份清单处理对应数据库与WAL/SHM。

## 开发与验证

本项目已使用Node24.16.0、npm11.13.0、Electron43.2.0、Windows x64运行；依赖按锁文件固定。首次准备及开发：

```powershell
npm ci
npm run setup:electron
npm run build
npm start
npm test
```

npm start默认使用.local/dev-profile；正式问题复现、桌面QA和安装验收必须显式隔离资料。按变更选择脚本：

```powershell
node scripts/qa-readability.mjs
node scripts/qa-assistant-layout.mjs
node scripts/qa-assistant-experience.mjs
node scripts/qa-card-markdown.mjs
```

这些脚本可传入隔离安装EXE；会写合成/公版验收资料并可能短暂显示测试窗口。真实模型和真实小说外发另按授权，不能因为脚本存在就当已运行。当前发布证据见[HANDOFF](HANDOFF.md)与[验收记录](docs/acceptance.md)。

Windows构建使用npm run package:windows，源码打包用npm run package:source。文档维护只重建当前源码ZIP/SHA，不自动重装程序或覆盖旧版本交付。[主管接手提示词](docs/开发与运维接管提示词.md) · [历史使用说明](docs/history/README-20261115-整理前.md)
