# 个人小说写作工作台

面向 Windows x64 的本地桌面应用。原创写作和外部参考资料分别存储，参考检索从已审核入库的知识卡返回消息、出处和原文入口。

接手开发从 [AGENTS](AGENTS.md) 与 [当前交接](HANDOFF.md) 开始。[维护地图](docs/maintenance.md) 说明代码与资料各自的位置，[构建和发布清单](docs/release-checklist.md) 提供隔离复验步骤。

## 安装与首次使用

1. 运行 `release/NovelStudio-0.1.19-x64-Setup.exe`。安装到当前用户，默认位置为 `%LOCALAPPDATA%\Programs\Novel Studio`。应用使用黑白钢笔尖图标。升级前先退出正在运行的工作台。
2. 打开 **资料与设置 → 打开资料目录**。需要语义检索时，把 `release/NovelStudio-LocalModel-Qwen3-Q8_0.zip` 内的 `model` 文件夹解压到这个目录，然后重启。首次查询会加载模型。也可先选择 **构建索引**。
3. **原创写作** 先显示「我的作品」书架，可按书名筛选、打开或新建作品。新建作品会自动创建第一卷、第一章。进入作品后，左栏专用于管理卷章和筛选标题。顶部 **返回书架** 会先保存再退出作品，作品菜单可重命名、导入或导出。**全文** 搜索当前作品的章节正文。右侧可新建和查看大纲、角色、设定，选择资料后可打开编辑，也可从 **…** 管理该条目。**对照** 用于阅读另一章。正文停输 800 毫秒后保存，失焦和切换时刷新，也可按 **Ctrl+S**。选中文字即可添加标记。章节可移入回收站，历史可从当前章查看和恢复。
4. 在 **参考库 → 导入标准结果包** 选择外部 Agent 的 ZIP，查看诊断和证据抽查后确认入库。顶栏可切换 **检索** 和 **书架**。在书架按书名找到作品，点进作品可读对应卷册、正文版本和知识卡。已有明确封面资源的作品显示原封面，其余显示书名封面。重新导入有内容变化的卡片时，逐项保留、接受或手工合并。写作时从右侧工具栏打开 **参考**，输入问题检索，点击证据进入对应正文版本。切换右侧工具后再打开 **参考**，可继续当前会话。

点卷册的 **开始阅读** 或知识卡的证据链接，会打开独立阅读页。顶栏可展开目录或调整阅读字号，**返回** 会回到进入前的位置。平时阅读不显示技术段号和版本哈希。需要旧正文时，在卷册的 **历史版本** 中按导入时间选择。

知识卡里的 `[1]`、`[2]` 对应下方带相同编号的原文入口。检索卡的 **查看完整卡片** 可展开分段内容。导入审核按本批出现的每种类别展示卡片和证据，逐项检查内容是否回答标题、是否符合类别。

恢复当前原创与参考资料时，使用应用导出的资料备份。发布目录中的 256 卷参考快照是知识卡整改前版本，可逐本导入其中的 `result.zip` 重建基线。卷范围、来源和版本见快照内清单。[验收记录](docs/acceptance.md)

安装包为本机构建的未签名发布产物。模型包单独分发，文件约 650 MB。默认资料目录为 `%LOCALAPPDATA%\Novel Studio`，包括 `library.sqlite` 及模型目录。卸载器按清单移除程序文件，资料目录可继续用于重装。

在正文工具栏打开 **写作设置** 可调纸色、横线或方格、字体、字号、行距、文稿宽度和段首缩进。文稿默认跟随窗口，可切换为限制最大宽度。正文隐藏滚动条，保留滚轮操作和空白章节的下滑空间。**资料与设置 → 外观** 中的主题色应用到整个软件，稿纸颜色仍可独立设置。偏好会自动记住，稿纸和缩进只影响屏幕显示。专注写作时，可按 **Esc** 或右上角的 **退出专注** 返回。

页脚可切换上一章和下一章。重开工作台后，点书架上标为 **继续写作** 的作品可回到上次的文档，正文版本一致时恢复光标和滚动位置。编辑工具栏的 **… → 一键整理** 或 **Ctrl+K** 会清掉行尾半角空格和制表符，将连续空行收为一行，可用 **Ctrl+Z** 撤销。**…** 中也可重命名当前文档和导出 TXT。

## AI 扩写

1. 打开 **资料与设置 → AI 扩写**，填写模型提供方的完整 Chat Completions 地址（通常以 `/v1/chat/completions` 结尾）、模型名和所需的 API Key。远程地址使用 HTTPS，本机服务可以用 HTTP。可为不同模型保存多套配置，在设置里选择当前模型。保存只写本机设置，**测试连接**只发送固定测试句。
2. 在原创章节中写下例如 `（补写许青的学院制服）`。选中整对括号或恰好选中括号里的提示，点击工具栏 **AI 扩写**。
3. 如有需要，勾选本书的大纲、角色和设定，再点 **生成预览**。长章节只发送选区前后的片段，创作资料也按长度限取。生成后会跳回正文，在括号原位用虚线下划线标出扩写。可滚动上下文，点 **保留这段** 后才写入并自动保存，也可用 **Ctrl+Z** 撤销。点 **恢复原文** 或按 **Esc** 丢弃预览。需要另一版时，可点 **重新生成**。

扩写只在主动生成时调用配置的服务，无长期记忆。外部 API 会收到本次提示与上面所列的正文和资料。需要正文留在本机时，填写本机生成服务。API Key 通过 Windows 密钥存储保护，保存后输入框用于录入新 Key，已存状态单独显示。同一接口地址的新配置可选择沿用已存密钥。应用备份不含扩写配置或密钥。参考库及本地语义索引不参与生成。服务需支持 OpenAI 兼容的非流式 Chat Completions 和 `max_tokens`。DeepSeek 官方接口可为每套配置开启思考模式。连接测试使用简短请求，正式扩写按该配置运行。 [DeepSeek 思考模式](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)

## AI 辅助参考检索

在 **资料与设置 → AI 辅助检索** 保存 OpenAI 兼容的完整 Chat Completions 地址、模型名称和 API Key，再测试连接。例如 DeepSeek 官方地址为 `https://api.deepseek.com/chat/completions`，模型名称按服务方提供的名称填写。

设置页按用途分类，切换分类会保留当前未保存的接口字段。参考检索输入框旁的 **接口设置** 可直接打开这一组。

在参考检索页勾选 **外部 AI 辅助**，即可用自然语言描述人物特征、情节机制或写作需求。模型先改写问题，再筛选本地召回的候选卡，结果可点回已有卡片和原文。启用时会向所配服务发送问题及最多 36 张候选卡的摘录，每张最多 2,400 字。接口异常时回退到本地检索，也可以随时取消。

检索和扩写分别保存配置，密钥使用系统加密。候选卡覆盖及模型判断仍会影响结果，未命中时可换描述或缩小作品、类别范围。

## 给外部拆书 Agent

从桌面「Novel Studio 拆书派工」拿三样材料给 Agent，分别为选定原文、`NovelStudio-拆书交接包-v1.0.zip` 和 `拆书Agent提示词-v1.0.md`。可选 EPUB／TXT 或已入库书目的同版正文 ZIP。Agent 在任意可写目录解压，完成公开资料研究、原文取证、制卡和离线验收。[交接说明](待拆书交接/README.md) · [本机原文位置](docs/maintenance.md#给外部-agent-准备原文)

新对话接管软件时，可直接使用[开发与运维接管提示词](docs/开发与运维接管提示词.md)。[项目交接](HANDOFF.md)记录应用版本、安装路径和参考库状态。

工作台从标准结果 ZIP 开始。收到结果后在「参考库 → 导入标准结果包」审核，再根据题单和原文证据复验。[九类制卡与验收](拆书规范包/知识卡质检与返工.md)

点开知识卡默认阅读内容，原文证据可按需展开。需要修改时点右上角 **编辑**，再保存或取消编辑。取消会丢弃本次未保存的卡片修改。 卡片支持二／三级小标题、粗体、列表和短引用。类别标记使用固定配色，检索标签按身份、关系、能力、条件代价等分组着色，未知分组使用中性色。编辑框显示原始 Markdown，纯文本卡也可直接阅读。

## 备份与恢复

单本参考书可从 **参考库 → 书架 → 作品 → 封存作品** 暂停使用。封存会从参考书架、作品筛选和关键词及语义检索排除该书。按 **书架 → 封存书目 → 作品 → 恢复到参考库** 可恢复原卡、原文和索引的使用。

使用 **资料与设置 → 导出备份**，将 ZIP 存到独立磁盘或用户选择的位置。备份包括原创正文、恢复稿、标记、历史、参考原文与图片、已审核卡片及索引数据。模型文件需单独保留。

恢复时选择该 ZIP 并确认。工作台先验证摘要、数据库版本和完整性，随后替换资料库，在资料目录留下 `before-restore-*.sqlite` 快照。要使用该快照回到恢复前的状态，先完全退出工作台，把当前 `library.sqlite` 及同名 WAL、SHM 文件移到另一个目录保存，再把选中的快照复制为 `library.sqlite` 并重启。

## 构建与复验

已用 Node 24.16.0、npm 11.13.0、Electron 43.2.0、Python 3.10.2 和 Windows x64 验证。Node 依赖按 `package-lock.json` 固定。Python 只用于外部转换和可选模型适配，使用离线 Qwen3 模型包运行桌面应用无需 Python。

```powershell
npm ci
npm run setup:electron
npm run build
npm start
npm test
python -m unittest discover -s 拆书规范包/tools/tests -v
```

`npm start` 使用项目固定的 Electron，默认资料目录为 `.local/dev-profile`。运行时下载不畅时，可用发布目录中校验过的 Electron ZIP 完成安装。开发环境可从 `.local/model` 加载语义模型。使用 NSIS 3.13 执行 `npm run package:windows` 生成安装程序和通用规范包，使用 `npm run package:source` 生成源码与交接包。[构建和发布清单](docs/release-checklist.md) · [本地模型说明](model/README.md)

```powershell
node --disable-warning=ExperimentalWarning scripts/qa-desktop.mjs
node --disable-warning=ExperimentalWarning scripts/qa-desktop.mjs "D:/隔离安装目录/Novel Studio.exe"
node --disable-warning=ExperimentalWarning scripts/qa-search.mjs
```

桌面复验使用全新的测试资料目录，并由测试程序向文件对话框提供预定路径。检索复验使用公版试拆查询集、中译轻小说和本机权重。具体验收、样本范围和剩余限制见 [验收记录](docs/acceptance.md) 与 [HANDOFF](HANDOFF.md)。发布目录另附可单独打开的验收记录包，包含对应知识库快照的分卷、整库恢复和检索记录。

## 反重力账号模型（0.2.1）

在“资料与设置 → AI辅助检索 → 检索模型来源”选择“反重力账号额度”，点击“刷新反重力模型”，选择模型和思考强度后“保存模型来源”。使用本机已登录Google账号的反重力CLI，无需填写Gemini API地址或Key；可用模型/额度以CLI与账号权限为准。可以用“测试反重力连接”发送固定测试句检查，不发送小说内容。模型目录中出现并不等于每个模型都已实际测试成功。

“自动”保留旧行为：优先已保存的兼容API，否则使用所选反重力模型；“兼容API”只使用API配置。来源切换不会删除现有API Key，切回即可继续使用。选模用于参考库“AI快速/AI深度翻书”；本地混合检索不消耗外部额度。真实AI检索按需发送问题、候选摘要和深度模式读取的参考原文。未安装/未登录CLI或额度不足时可继续本地检索，并会显示失败原因。

## 反重力扩写（0.2.2）

在“资料与设置 → AI扩写 → 扩写模型来源”选择“反重力账号额度”，刷新并选择Gemini模型/思考强度后保存。随后在原创章节选择括号提示，按原流程生成、预览和采纳。检索与扩写可以各选不同模型，互不覆盖；各自保留API配置。扩写初始仍选兼容API，只有用户明确选择反重力或自动才会使用账号模型。自动模式优先API，没有API配置时调用反重力。

反重力扩写输出正文，不输出检索JSON；失败、取消或选模变化时保留原稿，不自动换模型重写。只有用户主动生成时发送当前选区所需的有限章节上下文；创作资料仍默认不发送，由原有勾选项控制。连接测试只发固定测试句。

## Flash繁忙提示（0.2.3）

反重力Flash有时会返回服务端503“容量不足”。软件允许CLI短暂重试；若很快恢复，就清理CLI警告后返回实际结果。持续无有效输出时，首次容量警告后约20秒停止等待，显示503具体原因。检索仍返回本地结果，扩写保留原稿；不会暗中切换模型。可稍后重试或手动选择Carbon等其他可用模型。该处理不能增加Google端容量，也不代表Flash一直不可用。
