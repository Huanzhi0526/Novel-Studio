# 0006：原创扩写采用显式选区与独立模型

已接受，2026-11-10。用户授权在原创编辑器加入主动触发的扩写。此前「不提供生成建议」仍适用于参考库与检索侧栏；原创侧新增的仅是选区补写，参考拆书与导入协议不变。

- 作者选中完整成对括号或其中的提示。生成结果以独立的只读视图显示在正文选区原位，虚线标出候选文字。原编辑器和自动保存继续使用原稿。确认保留时校验正文、选区及文档身份，然后通过一个可撤销的正常编辑事务替换整个提示。按 Esc、恢复原文或切换章节可以丢弃预览。
- 每次仅向已配置的 Chat Completions 服务发送提示、当前章节必要片段及作者勾选的本书创作资料摘录。没有全书扫描、其他章节、参考卡、向量索引或长期记忆。
- 仅主进程联网。默认不配置任何模型地址；连接测试只发送固定测试句。支持本机 HTTP 和远程 HTTPS，不跟随重定向。API Key 用 Windows 系统加密，密文同时绑定接口地址，配置文件不进入 SQLite 或应用备份。
- 为兼容本机模型与用户自选服务，本版使用非流式 Chat Completions 的 `max_tokens` 请求格式。可取消，超时和异常结果不改稿。具体远程服务收到用户的端点与模型配置后再实测。
