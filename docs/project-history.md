## 派发边界

- `converter` 独占 `拆书规范包/tools`。输入原文和可选身份清单，输出可供外部 Agent 核对的草稿结果和诊断。主管复验 ZIP 和实际 EPUB。
- `protocol` 独占 `app/main/protocol*.mjs` 和协议测试。输出校验后结果、包摘要、已声明资源和诊断，读取数据库仅经只读 lookup 接口。主管复验实际导入事务。
- `embedding` 独占 `app/main/embedding.mjs`、`model` 和模型测试。输出可取消的本地向量接口和实际推理记录。主管负责检索融合、标注查询与桌面集成。
- `protocol` 完成协议初稿后接 T03，独占 `Writing.jsx` 与 `writing.css`，约定通过白名单 IPC 调用 WritingService。主管修复协议校验并独立测试整批事务、UI 保存及备份。

## 0.1.1 写作体验迭代

- 专注模式在 0.1.0 复现为退出按钮被隐藏、Esc 无效。新版提供常驻退出按钮及 Esc，并避开正在组合的中文输入。
- 正文、大纲、角色、设定各有目录入口。大纲、角色和设定可按标题筛选，能在保留当前正文的情况下从条目菜单打开侧栏速查。原有文档沿用其类型，SQLite 格式沿用 v1。
- 可即时调整主题色、纸色、空白／横线／方格、字体、字号、行距、文稿宽度及视觉缩进。偏好保存在应用本地，旧阅读字号会迁移到统一偏好。
- 定向审计复现并修复误替换选区、双击重复建章、切章等待时遗失输入、整书导出提前提交暂存稿等问题。后端预览和导出纯读取当前版本暂存稿。文档重排限定在同类条目。
- 交互参考阅文的官方桌面界面图和移动端说明。Windows 作家助手 5.24.0 登录后实机核对到作品页。编辑工具的参考来自官网界面图。[阅文桌面入口](https://zuojia.write.qq.com/) · [官方移动版说明](https://apps.apple.com/cn/app/id1044537226)

- 定向修复未自动保存时的标记跳转、键盘进入抽屉和返回、长回收站截断及标题弹窗的焦点范围。宽窗资料并排，窄窗抽屉可关闭。一键整理只处理半角行尾空白和多余空行，可撤销。
- 已升级当前用户安装，桌面快捷方式指向该安装。测试和发布证据见 [验收记录](acceptance.md)。真实 wenku8 成品样本的验收状态见上方余项。
