## 实现与取舍

1. 普通检索及分页：沿用AssistantSearch、SearchEngineV2、RetrievalEngineV2，单个长驻只读worker和20项有界FIFO，不更换向量库或降低候选上限。精确BLOB评分/ID顺序不变；24个分页状态跨请求保留，模式/范围/库代次匹配。取消真正终止当前worker，库或配置变化拒绝旧结果；无主线程扫描兜底。默认失败时才本地回退，分页不增加生成，首页导读保留。同卷同修订交集匹配证据；找不到重叠片段时保留实际已读范围作为临时只读卡，可打开同版原文，不写入知识库。
2. CLI准备与取消：异步EXE/系统代理发现、短时共享模型元数据、各用途和按书会话分离；保存模型可在临时目录故障时按原选择尝试，不静默换模型。operation.mjs统一总截止，排队可取消；启动FIFO只锁初始化/建会话，父助手不占槽等内部检索。提交固定来源/模型/配置，发送前再次校验，过期拒发。白名单日志记录操作/父ID、阶段/首输出/耗时/是否已发送，不记录原文、提示、stderr或凭证。仅未发送的会话锁允许一次受控重建。
3. 助手/嵌入/界面：检索任务独立模块、先检查20项上限、queued/running区分、领取校验本书本轮；重置清来源/失败摘要/旧任务，闲置180秒回收自己创建的资源。忙时单飞增量轮询，消息/来源版本与partial尾部减少全量返回；非活动视图保留已绘制内容。流式状态只扫描有界前缀，保留原始片段最终单次解析。嵌入启动取消能及时返回，其他等待者不受影响；无竞争预热，GPU→CPU/闲置卸载保留，回环断流/响应上限有明确错误。干净章节用checkpoint保留历史边界，省去重复全文stage/save。原生窗口背景与现有偏好首屏对齐。
4. 维护：SQLite快照、完整性/外键检查、原创全书查找及索引读取在独立worker，主进程保留小批写事务及独占替换。维护/退出等待只读句柄关闭，第二库替换或重开失败恢复双库；保留旧版兼容。写作和备份改变分别有回归。数据格式/引用标识/已有向量不迁移。
