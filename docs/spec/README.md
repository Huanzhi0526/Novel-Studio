# 施工 Agent 启动说明

> 历史施工资料（2026-11-09，v0.3）。正文保留当时的方案、限制和验证状态。当前版本、已支持能力与任务以 [HANDOFF](../../HANDOFF.md)、[维护地图](../maintenance.md) 和用户最新指令为准；不要据此重新初始化项目或撤回后续功能。

任务：实现个人小说写作工作台的 Windows 单人本地 MVP。先读施工方案.md、CONTEXT.md、docs/adr 和拆书规范包；方案中的已确认产品边界优先于历史方案。

首先检查用户指定的开发目录与现有文件，创建 HANDOFF.md，记录当前状态。不要把本交付包所在的聊天目录或它的上级仓库自动当作正式开发仓库。用户没有指定开发目录时，先询问这一实际执行位置，再创建应用项目。

第一项可执行工作为 T00 技术验证与 T01 协议校验。先用包内自创样例验证数据往返与诊断，再在授权样本上验证长篇与检索效果。主案为 Electron／React／TypeScript／SQLite 和本地 embedding worker；它是待实测的工程主案，不是已通过验证的环境。

务必注意：外部 Agent 拆书流程不属于工作台功能。不得添加原文预处理、拆书任务调度或拆书包导出界面。工作台只导入标准结果包并提供知识库管理与阅读检索；原创侧独立保留基础写作。

侧栏必须为“用户提问→结果消息”的对话框外观，返回真实知识卡与出处，不是生成式聊天。原创内容不得进入参考索引或自动提交给模型。

每阶段提交可运行产物、必要测试结果和更新后的 HANDOFF.md。没有通过真实推理、安装打包与恢复演练时，明确写未验证，不能以静态代码替代。技术验证失败先分析并记录替代方案，禁止擅自改云端 API 或扩大范围。

文件说明：施工方案.md 为主要规范；拆书规范包可直接与 TXT／EPUB 原文交给外部 Agent；示例小说为本包自创测试文字，不是真实作品分析。协议版本 draft-0.1 需通过首轮实现验证后冻结。

优先阅读施工方案第十二章。正常下载产物直接交给外部 Agent；T01 交付可复用的外部 TXT／EPUB 转换工具并复用已有目录，不要求用户手动整理。可选的 book.json 工作区适配必须先检查实际样本，不作为 EPUB 路线前置条件。主管可使用随包 GPTsol主管提示词.md。
