# 创作助手首版（0.2.4）

在左侧打开“创作助手”，选择原创作品，刷新反重力模型后选择模型和强度。展开“本书任务与记忆”，补充初始灵感、主旨、偏好和雷区并保存，再开始讨论。

助手先读取本书最新创作资料目录，按需读取大纲、人设、设定的全文（包含暂存稿）；单篇最多60000字符并明确标注截断。章节正文不自动提供。由助手调用reference_search委托现有检索AI，默认快速模式：意图展开、多路混合召回、AI筛选后返回参考卡；需要翻书核证时可请求deep模式。检索模型来源沿用“资料与设置→检索模型来源”，与创作助手模型分开。检索AI失败的本地回退会明确显示，不能称作AI筛选成功。参考卡可在界面打开。按需通过Bing RSS搜索网络，提供摘要和来源链接，暂不读取网页全文。网络服务不可用时工具返回明确错误，不伪造结果。

用户主动发送时，相应资料会发给选择的反重力模型，复用CLI现有账号；联网工具仅发送搜索词。不得在后台自动开展全库扫描或原创分析。各书会话、记忆和资料工具相互隔离。

## 文件和会话

资料目录下 `assistant-books/<work_id 的 UTF8 十六进制>/` 是每本书的固定工作区：

- `AGENTS.md`：任务、主旨、偏好与长期记忆，工作台和助手均可编辑；自动写入前保留 `.previous`。
- `chat.json`：工作台显示的讨论记录，不另做语义记忆。
- `session.json`：所选模型和CLI会话ID；CLI历史仍由反重力自己的全局目录保存。

同一书的连续消息复用ACP会话。重启后，在CLI声明支持 `loadSession` 时尝试 `session/load`；不支持或加载失败则创建新会话并提供最近最多12条/24000字符的讨论。长期要点仍以AGENTS.md和最新创作资料为准。切换模型另开会话；“重新开始讨论”清空本地讨论并保留记忆，不代表删除CLI历史。未接入 `/clear`，没有清理既有CLI记录。

AGENTS.md在新连接首轮显式提供，不依赖反重力全局规则自动发现。模型输出的建议与作者确定的设定必须区别记录。任务规则要求只记已确认决定，待定方案单独标明；作者仍应检查记忆，可手动修订。

## 实现与边界

复用现有 `AgyFlashClient` 的ACP传输、取消和容量错误处理，新增可选assistant会话模式；原扩写与检索仍为独立单轮。使用反重力自己的Agent工具循环，不引入新的Agent框架或记忆数据库。

`AssistantService` 将专用MCP HTTP工具仅绑定127.0.0.1，使用每工作区随机Bearer令牌；令牌不写入记忆或交接文档。专用工具允许单次调用，其他CLI工具请求显示给用户确认，不自动授予终端或任意文件操作。工具权限参考官方[ACP接入](https://antigravity.google/docs/ide/extensions/acp/)和[规则文件](https://antigravity.google/docs/rules/)，直接复用接口，不复制框架代码。

旧的应用数据库备份ZIP没有包含这些文件；需额外备份整个assistant-books目录。程序升级前全资料目录备份会包含它们。助手本身不写原创或参考数据库。

测试：`npm test`；隔离桌面验收：`node scripts/qa-assistant.mjs`，可传入隔离安装EXE。真实模型工具调用使用完全合成资料；不能以此宣称任意真实作品的建议质量已获验证。记录见HANDOFF和本机.local/assistant-v024。


0.2.5响应修复：SQLite读取、向量评分和检索AI的流程调度在独立只读工作线程执行；模型请求仍交给现有检索配置及账号客户端，向量计算仍使用共享本机embedding服务。向量BLOB逐条读取，不再整批载入主进程。工作台界面线程负责异步转交模型请求和显示结果。搜索未结束时可以切换页面，停止会终止本任务工作线程；不删除聊天、记忆或库内向量。
