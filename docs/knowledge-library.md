## 选书口径

按《这本轻小说真厉害！》2017–2026 版中的高位、新作与多年入榜记录筛选，再以轻小说文库榜单补充和排序。站点实时名次无法核实的作品暂不填排名。正式版、作者网络版、外传分开记版本，不混用段号和证据。

暂缓正文达到 300 万字符的作品。仅有卷数的作品先标长度待核，拿到合法正文后按标准化正文实测。优先冒险奇幻、推理、能力体系、宅向恋爱喜剧。耽美为主、NTR 为主、轻文学和以青春伤痛为主的恋爱作品排除。仅含少量 NTR 要素的作品按主轴筛选。
