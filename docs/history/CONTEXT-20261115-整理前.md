# 个人小说写作工作台

本项目管理个人原创作品，以及用于参考的外部作品资料。原创资料与外部参考知识保持独立。

原创区负责作品组织、写作、资料和主动触发的 AI 扩写。参考区接收外部标准结果包，经审核后提供检索与原文阅读。外部拆书和正文标准化由工作台之外的流程执行。当前部署和操作范围见 [HANDOFF](HANDOFF.md)。

## 项目术语

### 作品与资料

**原创作品**：用户正在创作的小说及其正文、大纲、人设和设定。
_Avoid_：参考作品、参考知识库

**原创标记**：用户附着于原创正文位置的简单标签和备注，例如伏笔、铺垫或关键句。
_Avoid_：知识卡、自动伏笔分析

**AI 扩写**：在原创章节选中括号提示后，用户主动发起的单次正文补写。预览确认后才替换选区，范围限当前章节片段和可选的本书创作资料。
_Avoid_：参考检索回答、自动续写、长期对话记忆

**参考作品**：用于阅读、核对和提取参考知识的外部小说作品。
_Avoid_：原创作品

**参考作品分卷**：同一参考作品下可以独立导入或补充的卷；同一轻小说系列的不同卷归属于同一参考作品。
_Avoid_：独立系列、正文修订版

**正文修订版**：已有卷正文发生修订后形成的另一版本，不等同于给作品补充一卷。
_Avoid_：补卷

**原始文件**：外部取源阶段保留的 EPUB 或 TXT。工作台导入外部流程交付的标准结果 ZIP。
_Avoid_：标准化正文、知识卡

**标准化正文**：经过格式整理、保留段落并附有稳定段落标识的参考作品文本。
_Avoid_：原始文件、章节结构

**章节结构**：对参考作品的卷、章、序章、尾声、幕间及后记等层级与正文范围的描述。
_Avoid_：正文、场景分隔

**场景分隔**：作品中表示场景转换的边界，不天然等同于章节边界。
_Avoid_：章节

### 参考知识与交换

**知识卡**：回答参考作品中一个具体检索问题的结构化条目。卡名、类别、正文和原文证据共同限定问题。跨卷人物与专题卡记录已核实的阶段变化，事实与分析分开标示。
_Avoid_：原创资料、整本原文切片

**参考知识库**：由外部参考作品知识卡构成的可检索资料集合。
_Avoid_：原创资料库、原文书架

**参考作品封存**：从日常书架、作品筛选、关键词和语义检索中暂时排除一部参考作品。其卡片、同版正文和引用仍保存在本机，恢复单本后重新参与检索。

**拆书规范包**：提前定义、可复用的数据规范、任务要求及输出样例集合；用户将它与原文一起交给外部 Agent。
_Avoid_：工作台生成的专书任务包、内置 AI 拆书引擎

**标准结果包**：外部 Agent 产出的标准化正文、段落索引、章节结构、知识卡及处理情况说明的集合，供工作台导入校验。
_Avoid_：拆书规范包、已审核知识

**NTS**：原文标准化约定的暂定名称，正式规范尚未冻结。
_Avoid_：行业标准、已完成标准

**NKS**：知识卡数据约定的暂定名称，正式规范尚未冻结。
_Avoid_：行业标准、已完成标准
