九类都存在能定位、却在检索结果中只提供单场面或缺少条件与后果的卡。已发现的旧工作流使用卷级前／后两份草稿，按标题生成 UUID，验收要求足够多的查询与有效范围。跨卷脚本再取各卷既有卡的部分证据。原始卡在跨批汇总之前没有统一的实体身份、事件账本与分类型实质验收。生产协议的结构校验能确认段落存在，内容缺口仍须由人工或独立复核补上。

整改建议把每部书的原文版本、全卷范围和未核处先写入账本。任何历史卡的去向记录为保留、补强、归并关联或待证据，保留卡片 ID 及已有编辑。优先以有早中晚证据的总卡覆盖核心实体、主线、组织及机制；范围较小但可独立回答的问题仍可保留短卡。字数和证据宽度是初筛线索，单卡验收要检查它具体回答了什么，以及每项主张能否在相应版本定位。
