# 阅读体验优化（0.2.10）

发布状态和实际验证证据以HANDOFF顶部为准。本轮由用户提出四项调整：简约滚动条、减少常驻注释小字、助手输出易读、检索卡片减少滚动。

## 实现与边界

- 使用浏览器原生滚动行为，统一6px宽/高的扁平滚动条，透明轨道、低对比滑块、悬停加深。键盘、滚轮和触控板行为不变，无额外滚动库。
- 助手输入区移除常驻快捷键/发送范围小字。快捷键保留在输入框悬停提示；发送范围保留于“模型与记忆→使用说明”。检索发送范围写入模式按钮悬停提示；取消失准的默认模型耗时估计。模型来源、连接测试说明折叠；卡片只读说明和重复纸张提示移除，错误/未完成/未保存等必要状态继续显示。
- 每次助手提示追加简短排版要求：先回答要点、分段说明，分幕大纲按章节/目标/阻力转折/人物情绪分节；长段落不塞宽表，短对比可用标准Markdown。明确作者要求时仍可用表格，不修改本书AGENTS.md或现有会话文件。
- 历史和新回复使用同一显示处理：GFM短表正常显示；长单元格超过90字或全表文本超过450字时转为逐行分节，首列为标题、其余列按表头标注。简单<br>令牌转为安全换行，其他HTML沿用react-markdown默认的文本显示，不引入rehype-raw；图片不加载，链接按既有方式仅显示来源。
- 对于各行被挤到同一行的管道表，只在表头、分隔行、每行列数都明确匹配时补显示换行；不修改代码围栏，不擅自重构不完整或有歧义的内容。只转换渲染输入，chat.json原字节不改。不能保证任意模型的任意破损格式都能自动修复。
- 对话内参考卡采用短预览：优先既有creative_takeaway，否则取原卡摘录（最多160字加省略号，三行显示），标题保留，全文通过既有卡片弹窗打开，证据折叠。宽屏并排、窄侧栏自动单列。卡片内容/引用身份/召回排序不改；不把摘录当新AI摘要。
- 分页仍使用现有cursor和用户“加载更多”，本轮通过预览和网格减少每批结果的阅读高度，不自动发出后续检索或扩大AI候选范围。卡片详情仍保留完整受限Markdown与原文证据。

## 复用依据

- [react-markdown官方插件示例](https://github.com/remarkjs/react-markdown#use-a-plugin)：现有渲染器支持remark插件，官方示例使用remark-gfm添加表格。
- [remark-gfm README](https://github.com/remarkjs/remark-gfm)：GFM语法解析，MIT许可、ESM、Node16+；本项目Node24及react-markdown10.1.0，固定4.0.1并更新锁文件，构建与测试核验兼容。仅复用解析，不自行实现通用Markdown解析器。
- 本地新增assistant-markdown.mjs仅补本项目的保守换行修复和长表阅读转换；未引入完整Agent/编辑器/HTML执行框架。

## 维护与验收入口

- 主要入口：Assistant.jsx、assistant-markdown.mjs、assistant-presentation.mjs、card-preview.mjs、ui.jsx、Conversation.jsx、app.css、assistant.css、reference-bookshelf.css。
- npm test覆盖长表/短表、代码与转义保护、未知HTML原句不丢、预览不改卡片或证据、每轮排版要求。
- node scripts/qa-readability.mjs [隔离安装EXE]：使用合成表格/12张长卡、可见不抢焦点窗口，检查三列/窄窗、6px滚动条、全文入口、深色截图及聊天文件字节不变；不调用外部模型。
- qa-card-markdown、qa-card-viewer、qa-retrieval、qa-desktop继续验证完整卡片、编辑保留（旧卡）、证据跳转与写作恢复。预览断言改为短摘录，完整Markdown/标签断言仍在详情弹窗内保留。
